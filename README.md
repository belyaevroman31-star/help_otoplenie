# Отопление — мобильное PWA-приложение

Прогрессивное веб-приложение (PWA) с сводкой нормативных документов, нормами воздухообмена, тепловых нагрузок и схемами радиаторного отопления. Работает офлайн, устанавливается на Android.

## Возможности
- Установка на Android через меню браузера (Chrome / Brave / Edge / Yandex).
- Полная работа в офлайн-режиме (service worker кэширует всё приложение).
- Модальные окна со схемами радиаторного отопления и описанием сборки.
- Плавающая кнопка «наверх».

## Структура репозитория
```
pwa/
├── index.html            # главная страница приложения
├── manifest.webmanifest  # манифест (имя, иконки, отображение)
├── sw.js                 # service worker (кэш и офлайн)
├── icons/                # иконки приложения
│   ├── icon-192.png
│   ├── icon-512.png
│   ├── icon-512-maskable.png
│   ├── icon-180.png      # для iOS (apple-touch-icon)
│   └── favicon-32.png
├── images/               # изображения схем радиаторного отопления
└── README.md
```

## Публикация на GitHub Pages

Требования для установки PWA на Android: HTTPS, валидный манифест и service worker. GitHub Pages даёт всё из коробки.

1. Создайте репозиторий на GitHub (например, `otoplenie-svodka`).
2. Загрузите **содержимое папки `pwa`** в корень репозитория:
   ```
   index.html, manifest.webmanifest, sw.js, icons/, images/, README.md
   ```
3. В репозитории откройте **Settings → Pages**:
   - Source: **Deploy from a branch**
   - Branch: **main** / **root** → **Save**
   - HTTPS включён по умолчанию.
4. Дождитесь сборки (1–2 минуты). Ссылка: `https://<ваш-логин>.github.io/<имя-репозитория>/`
5. Если у вас уже есть сайт на `<login>.github.io`, можно разместить как подпапку; тогда поправьте `start_url`, `scope` и пути в `sw.js`/`PRECACHE` (добавьте префикс подпапки).

## Установка на Android (пошагово)

- Откройте ссылку GitHub Pages в **Chrome** (или Brave/Edge) на Android.
- Дождитесь полной загрузки страницы (service worker кэширует приложение).
- Нажмите **⋮ (меню) → «Установить приложение»** (или баннер «Установить» внизу).
- Подтвердите — приложение появится на рабочем столе как отдельное приложение (без адресной строки).
- Все данные сохраняются офлайн; обновления подтягиваются при наличии сети при открытии.

### Проверка после публикации
- Chrome DevTools → Lighthouse → PWA — должно быть ~100.
- В Chrome на ПК: меню → «Установить "Отопление"…» — приложение установится и как PWA на рабочий стол ПК.

## Локальный запуск (без установки на телефон)
```bash
# из папки pwa
python -m http.server 8080
```
Открыть `http://localhost:8080`. Для установки на телефон доступ, локальный сервер не подходит — только HTTPS (GitHub Pages).
